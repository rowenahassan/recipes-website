# What's For Dinner 🍽️

A responsive recipe web application built using **Vanilla JavaScript** and **Bootstrap**.  
The app displays a random meal suggestion with full details including ingredients, cooking steps, nutrition facts, and helpful chef tips.

## 🔍 Features
- Random recipe generator
- Dynamic content rendering using JavaScript
- Ingredients & step-by-step instructions
- Nutrition information for each recipe
- Chef tips section
- Time warning for long recipes
- Fully responsive layout (mobile, tablet, desktop)

## 🛠️ Built With
- HTML5
- CSS3
- Bootstrap
- JavaScript (Vanilla JS)
- Font Awesome

## 🎯 What I Practiced
- Working with arrays & objects
- DOM manipulation
- Conditional rendering
- Loops and dynamic UI updates
- Clean code structure
